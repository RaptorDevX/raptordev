Strict Manager-Based Separation

TrimMasterX is designed to be highly clean, structured, and decoupled at the code level. It adheres to an intentional manager-driven pattern to minimize coupling, simplify maintenance, and streamline runtime updates:

PatternManager Parses custom banner configurations and outputs detailed premium design matrices.
ShieldManager Generates and applies layered BannerPattern metadata to default item-stack shields.
TrimManager Sets and removes Bukkit armor trim template and material metadata directly on client gear.
GuiManager Manages dynamic player inventory screens, custom lore overlays, and clicks cancellation.
DataStorage Stores user favorites and recent customization history asynchronously using YAML buffers.
NpcIntegrationManager Soft-hooks Citizens NPCs cleanly at boot time without introducing static dependencies.

TrimMasterX includes native soft Hooks. If Citizens, DeluxeMenus, placeholderAPI, or Vault economy are absent, features gracefully deactivate without warning logs. Connect via Discord for custom enhancements.
